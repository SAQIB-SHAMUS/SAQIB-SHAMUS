## 🌟 Featured Projects

### [NXFileForensics](https://github.com/SAQIB-SHAMUS/NXFileForensics-Offline-File-Investigator)

An offline, zero-dependency CLI for analyzing files locally. It can inspect file types, detect duplicate content, spot encrypted or unusual data, extract readable strings, and compare files byte-by-byte.

It’s a strong example of practical engineering focused on security, data investigation, and tooling that works without external dependencies.

**Tech Stack:** Go | CLI | File Analysis | Security Tools

### [Project Automations](https://github.com/SAQIB-SHAMUS)
